# Loupe Vision

> **Loupe is an AI Product Design Partner that observes how software is built, identifies opportunities for improvement, teaches the reasoning behind those opportunities, and generates implementation-ready work for AI coding agents.**

## What Loupe Is

Loupe sits between product design and implementation. It observes, teaches, and generates — in that order.

- **Observes** by recording how people interact with their products. Clicks, scrolls, DOM changes, console errors, network timing, and narrated thoughts.
- **Identifies** opportunities for improvement using deterministic analysis and AI reasoning. Not bugs — opportunities.
- **Teaches** why each opportunity matters. Design principles, best-in-class patterns, evidence from the session.
- **Generates** production-ready implementation briefs that Claude Code, Cursor, Codex, or any AI coding agent can execute without rewriting.

## What Loupe Is Not

Loupe is **not** a UX auditing tool. A UX audit produces a report. Loupe produces a package that an AI agent can implement.

Loupe is **not** a design tool. It doesn't replace Figma or Sketch. It bridges the gap between a recorded experience and an implemented improvement.

Loupe is **not** a monitoring tool. It doesn't watch production traffic. It watches you build, so it can help you build better.

## The Long-Term Vision

One sentence: **Loupe is the operating system for AI-assisted product development.**

The loop:

```
Record → Review → Select → Explain → Redesign → Build → Verify → Compare → Repeat
```

Every improvement is tracked. Every score is measured. Every prompt is versioned. Every benchmark creates a baseline for the next iteration.

The product accumulates:
- **Knowledge** — product specs, design research, implementation patterns
- **Evaluation** — fixtures, benchmarks, evals that measure quality objectively
- **Generation** — versioned prompts that produce consistent output
- **Verification** — automated checks that new builds maintain or improve quality

This accumulation compounds. Six months from now, Loupe won't just review your product. It will understand your product's design system, your team's conventions, your users' behaviors, and what "better" means in your context.

## Why This Matters

The gap between "this feels off" and "this is fixed" is the most expensive distance in software development. It involves:
1. Noticing the issue
2. Articulating why it matters
3. Designing a solution
4. Writing the code
5. Testing it

Loupe collapses steps 1-4 into a single loop. The developer records what they see, and Loupe generates the implementation package. The AI coding agent does step 4. The developer validates step 5.

This is the fastest path from observation to implementation.
