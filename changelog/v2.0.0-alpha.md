# Changelog

## v2.0.0-alpha (June 27, 2026)

**Initial alpha release.** Loupe is an AI Design Engineering Companion that records product sessions, identifies improvement opportunities, and generates implementation-ready packages for AI coding agents.

### Features

**Extension Recorder (v3 UX)**
- 5-state popup: Permission, Ready, Recording, Saved, Recovered
- Agent Workspace card with visual identity badges
- Config overlay for per-project agent workspace settings
- Capture health grid (Clicks, Screenshots, DOM, Audio)
- Session-relative timestamps on all events
- MV3 durability (chrome.storage.local, alarm heartbeat, restore on wake)
- Offscreen document for mic audio capture

**Analysis Pipeline**
- Deterministic checks: console errors, touch targets, slow requests, SPA health, narration
- Design drift checks: color tokens, fonts, radii, spacing, shadows
- 5 AI reviewer personas (PM, Designer, Design Systems, Accessibility, Frontend)
- Merge + dedupe across reviewers
- Evidence model (screenshot refs, DOM snapshot refs, event refs, URL, selector)
- Scoring engine (100 base, severity-weighted, per-category)
- Top 5 prioritization
- v2 artifact format (opportunities.json, referenced screenshots)

**Three Reasoning Modes**
- Explain: deterministic design principles + optional AI enrichment
- Redesign: 8-dimension proposed experience
- Build This: 11-section implementation brief + directory package

**Destination Router**
- 7 providers: local, claude-code, cursor, codex, gemini, clipboard, custom-command
- Per-project configuration
- Provider-specific wrapper files (CLAUDE.md, cursor-prompt.md, etc.)
- Path traversal protection

**Target Design Mode**
- Accepts PNG, JPG, WebP, HTML, Markdown targets
- Visual gap analysis (6 dimensions)
- Implementation guidance (keep, replace, modify, update)
- Target artifact copied into package

**Infrastructure**
- LLM router (task-based model selection, 5 providers)
- .env support (env var → ~/.loupe/.env → project .env)
- SaaS mode (LOUPE_API_URL + LOUPE_API_KEY)
- 8 hardening tests, CI workflow
- All architecture decisions documented (9 ADRs)

### Known Issues
- `llm/types.ts` uses synchronous `require()` in ESM context (runtime risk on strict ESM)
- `extension/package.json` still named `spotter-extension`
- No extension browser tests
- No loupe eval command yet
