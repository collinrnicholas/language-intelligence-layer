# Research: Linear UI Patterns

**Source:** linear.app
**Extracted:** June 2026

## Notable Patterns

### 1. Cmd+K Universal
- Every action available through command palette
- Search, create, navigate, assign, set labels — all from one prompt

### 2. Infinite Scroll + Virtual List
- No pagination to interrupt flow
- Hundreds of items loaded and navigable instantly

### 3. Progressive Disclosure in Sidebar
- Workspace name → Projects → My Issues → Filters
- Collapse levels to reduce noise

### 4. Consistent Delete Flow
- Undo bar (not confirmation modal) for most destructive actions
- "Undo" banner appears briefly, then commits

### 5. Dark Mode as Primary
- Dark is the default, not an afterthought
- Light mode is available but clearly secondary

## Why This Matters for Loupe

Linear demonstrates "interaction design as product philosophy." Every pattern serves speed. The Cmd+K pattern and undo-bar approach are references for reducing friction.
