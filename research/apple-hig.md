# Research: Apple Human Interface Guidelines

**Source:** developer.apple.com/design/human-interface-guidelines
**Extracted:** June 2026

## Key Principles for Loupe Reference

### 1. Deference
- UI should defer to user content and tasks
- Chrome should be minimal, content should breathe
- Don't let UI compete with user goals

### 2. Clarity
- Text is legible at every size
- Icons are precise and lucid
- Decoration is subtle and appropriate

### 3. Depth
- Visual layers communicate hierarchy
- Motion provides feedback and context
- Realistic lighting and shadows ground the interface

## Why This Matters for Loupe

HIG is the most mature design system reference. "Deference" maps to Loupe's principle that the extension popup should not be a report viewer. "Clarity" maps to typography and spacing checks. "Depth" maps to visual hierarchy detection.
